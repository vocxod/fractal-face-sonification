# 🎹 Fractal Image Sonification Engine
> **Универсальный иерархический секвенсор сонификации изображений на основе пространственно-заполняющих кривых.**

Проект находится на стыке **Компьютерного зрения (Computer Vision)**, **Глубокой математики фракталов** и **Сенсорного замещения (Sensory Substitution)**. Программа преобразует геометрию, контуры, контрасты и яркость любых двумерных графических матриц (изображений) в многослойную полифоническую музыку.

---

## 👁️ Назначение и Сферы применения
1. **Звуковое зрение (Инклюзия):** Создание интуитивного фрактального аудио-языка, позволяющего незрячим людям «слышать» и распознавать контуры, формы и границы графических объектов.  
   * *Пример:* Трансформация **человеческого лица** в индивидуальный звуковой портрет для распознавания мимики или «слышания» эмоций собеседника.
2. **Акустический паспорт / Фонорингтон:** Генерация уникальных, математически инвариантных мелодий на основе биометрических или графических данных.  
   * *Пример:* Фотография звонящего контакта из телефонной книги преобразуется в присущую только ему вирусную мелодию вызова.
3. **Платформа со-творчества:** Инструмент Science-Art, где пользователь выступает в роли дирижера и композитора, настраивая оркестровку, гаммы и траектории сканирующего луча.

---

## 🧠 Математическая архитектура (ДРАКОН-Логика)

Алгоритм разбивает плоское изображение на иерархические слои и преобразует графическое пространство во время по следующим правилам:

### 1. Квадродерево (Quadtree)
Входная графическая матрица нормируется до строгого квадратного формата $256 \times 256$ пикселей. Алгоритм строит полное квадродерево, вычисляя среднюю яркость в каждом узле. Уровни вложенности дерева жестко привязаны к музыкальным регистрам, создавая полифоническое наложение треков:
* 🎚️ **Уровень 2 (Сетка 4x4, 16 узлов):** Слой БАСА (Макро-такты / Целые ноты). Отображает крупные формы и фундамент изображения.
* 🎹 **Уровень 3 (Сетка 8x8, 64 узла):** Слой МИД / Пианино / Гусли (Четвертные ноты). Озвучивает средние контуры и тени.
* 🪵 **Уровень 4 (Сетка 16x16, 256 узлов):** Слой ТОП / Рожок / Флейта (Шестнадцатые ноты). Отвечает за микро-детали и текстуры.

### 2. Пространственно-заполняющие кривые (Space-Filling Curves)
Обход узлов на каждом уровне параметризован фрактальными траекториями:
* **Развертка Мортона (Z-кривая):** Обход через битовое перемежение координат X и Y. Дает динамичный, синкопированный, ломаный цифровой ритм.
* **Кривая Гильберта:** Абсолютно непрерывный обход без пространственных скачков (следующий пиксель всегда граничит с предыдущим). Генерирует плавное легато, идеальное для пространственного распознавания форм слухом.

### 3. Трафаретное вычитание пауз
Если средняя яркость графического сектора ниже установленного порога, инструмент данного регистра **берет паузу**. Счетчик времени накапливается в дельта-время MIDI-трека, формируя ломаный, уникальный для каждого рисунка ритмический узор.

## 🛠️ Быстрый старт (Инструкция для Debian 12 / Ubuntu)

Проект оптимизирован под **Python 3.11** и использует изолированное окружение.

### 1. Клонирование и развертывание окружения
```bash
# Перейдите в папку проекта
cd FractalSonicFace

# Создайте и активируйте виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# Обновите pip и установите зависимости
pip install --upgrade pip
pip install -r requirements.txt
```

### 2. Запуск интерактивного стенда
```bash
streamlit run main.py
```
После запуска откройте в браузере локальный адрес (по умолчанию `http://localhost:8501`).

## 🎛️ Инструкция пользователя (Как управлять оркестром)
1. **Кадрирование (Интерфейс JavaScript Canvas):** Загрузите графический файл. С помощью мыши или тачскрина выделите ключевую область строгим квадратом.  
   * *Для примера с лицом:* Масштабируйте портрет так, чтобы центры глаз попали строго в **синие калибровочные мишени Узлов 0 и 1 первого уровня** (координаты `(64,64)` и `(192,64)`). Это гарантирует музыкальную инвариантность и узнаваемость трека.
2. **Настройка лада (Гаммы):** Переключайте лады (например, глубокий *Древнерусский Обиходный лад*, мажор или космическую *Минорную пентатонику*). Математический квантователь частот мгновенно перестроит ноты, исключая какофонию.
3. **Сборка ансамбля:** Назначайте народные (Гусли, Жалейка, Рожок) или синтезаторные инструменты на каждый слой независимо.
4. **Генерация:** Нажмите кнопку **«▶ ИГРАТЬ»**. Встроенный аддитивный синтезатор сгенерирует аудиопоток прямо в памяти Python. Вы сможете прослушать трек во встроенном плеере и скачать готовый `MIDI-файл` для профессиональной работы со звуком.
