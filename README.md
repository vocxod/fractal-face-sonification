# 🎹 Fractal Face Sonification Engine
> **Универсальный иерархический секвенсор сонификации изображений по пространственно-заполняющим кривым.**

Проект находится на стыке **Компьютерного зрения (Computer Vision)**, **Глубокой математики фракталов** и **Звукового зрения (Sensory Substitution)**. Программа переводит геометрию, пропорции и контрасты человеческого лица в многослойную полифоническую музыку.

---

## 👁️ Назначение и Социальная миссия
1. **Звуковое зрение для слабовидящих:** Создание интуитивного фрактального аудио-языка, позволяющего мозгу незрячего человека «слышать» и распознавать контуры и выражения лиц.
2. **Акустический паспорт / Фонорингтон:** Генерация уникальных, математически инвариантных мелодий вызова на основе антропометрических данных ваших друзей и близких.
3. **Платформа со-творчества:** Инструмент Science-Art, где пользователь выступает в роли дирижера, настраивая оркестровку, гаммы и траектории луча.

---

## 🧠 Математическая архитектура (ДРАКОН-Логика)

Алгоритм разбивает плоское изображение на иерархические слои и преобразует пространство во время по следующим правилам:

### 1. Квадродерево (Quadtree)
Входная матрица лица приводится к строгому квадрату $256 \times 256$ пикселей. Алгоритм строит полное квадродерево, вычисляя среднюю яркость в каждом узле. Уровни вложенности дерева жестко привязаны к музыкальным регистрам (полифония):
* 🎚️ **Уровень 2 (Сетка 4x4, 16 узлов):** Слой БАСА (Макро-такты / Целые ноты).
* 🎹 **Уровень 3 (Сетка 8x8, 64 узла):** Слой МИД / Пианино / Гусли (Четвертные ноты).
* 🪵 **Уровень 4 (Сетка 16x16, 256 узлов):** Слой ТОП / Рожок / Флейта (Шестнадцатые ноты).

### 2. Пространственно-заполняющие кривые (Space-Filling Curves)
Обход узлов на каждом уровне параметризован фрактальными траекториями:
* **Развертка Мортона (Z-кривая):** Обход через битовое перемежение координат. Дает динамичный, синкопированный, ломаный ритм.
* **Кривая Гильберта:** Абсолютно непрерывный обход без пространственных скачков. Генерирует плавное легато, идеальное для чтения форм слабовидящими.

### 3. Трафаретное вычитание пауз
Если средняя яркость фрактального блока ниже порога, установленного пользователем на панели, инструмент **берет паузу**. Счетчик времени накапливается в дельта-время MIDI-трека, рождая уникальный синкопированный ритмический рисунок лица.

## 🛠️ Быстрый старт (Инструкция для Debian 12 / Ubuntu)

Проект оптимизирован под **Python 3.11** и использует изолированное окружение.

### 1. Клонирование и развертывание окружения
```bash
# Перейдите в папку проекта
cd FractalSonicFace

# Создайте и активируйте виртуальное окружение
python3 -m venv .venv
source .venv/bin/activate

# Обновите pip и установите зависимости
pip install --upgrade pip
pip install -r requirements.txt
```

### 2. Запуск интерактивного стенда
```bash
streamlit run main.py
```
После запуска откройте в браузере локальный адрес (по умолчанию `http://localhost:8501`).

## 🎛️ Инструкция пользователя (Как управлять оркестром)
1. **Кадрирование (Интерфейс JavaScript Canvas):** Загрузите фотографию. С помощью мыши или тачскрина выделите лицо строгим квадратом так, чтобы центры глаз попали строго в **синие калибровочные мишени Узлов 0 и 1 первого уровня** (координаты `(64,64)` и `(192,64)`). Это гарантирует музыкальную инвариантность.
2. **Настройка лада (Гаммы):** Переключайте лады (например, глубокий *Древнерусский Обиходный лад* или космическую *Минорную пентатонику*). Математический квантователь частот мгновенно перестроит ноты, исключая какофонию.
3. **Сборка ансамбля:** Назначайте народные (Гусли, Жалейка, Рожок) или синтезаторные инструменты на каждый слой независимо.
4. **Генерация:** Нажмите кнопку **«▶ ИГРАТЬ»**. Встроенный аддитивный синтезатор сгенерирует аудиопоток прямо в памяти Python. Вы сможете прослушать трек лица во встроенном плеере и скачать готовый `MIDI-файл` для профессиональных звуковых редакторов.
